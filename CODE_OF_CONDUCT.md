# Code of Conduct

This project adopts the **Contributor Covenant** (version 2.1) as its code of
conduct. The full, canonical text is maintained by its authors and is available
here:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: we want participation in this project — issues, pull requests,
discussions — to be a respectful and harassment-free experience for everyone,
regardless of background or identity. Be kind, assume good faith, and focus on
what is best for the community.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to
the maintainer:

- **pehqge@gmail.com**

Reports will be handled confidentially. The maintainer is responsible for
clarifying standards and may take any action deemed appropriate, up to and
including removing a contributor from the project's spaces.
